# kotlin-js-demo - zum Reproduzieren von Build-Related Issues

Es gibt unter `internal/sandbox/kotlin-js-demo` das "Gegenstück" ohne unsere Build-Konfiguration.
Diese Projekte sollten synchron gehalten werden.

Damit kann man das Ergebnis eines sehr einfachen Builds (in Sandbox) mit unserem Build vergleichen und potenzielle Fehler (z.B. Dead Code Elimination) reproduzieren.
