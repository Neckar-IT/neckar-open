# typescript-react-ui-primitives

`@neckar-hub/typescript-react-ui-primitives` enthält die shadcn/ui-Primitives im Output der shadcn CLI.

## Regel

Nur die shadcn CLI schreibt Dateien unter `src/`, ausgenommen `src/tailwind-sources.css`. Eine Datei unter `src/` gleicht dem Output von `shadcn add <name> --yes --overwrite` mit anschließendem Marker und `oxfmt`; `src/shadcn-theme.css` gleicht dem Output von `shadcn add style --yes --overwrite`.

`typescript-react-ui` kapselt jede eigene Anpassung (Variante, Klasse, Prop, Hook) in einem Wrapper unter `internal/open/commons/typescript/typescript-react-ui/src/components/primitives/<name>/`.

## Primitives erzeugen

```bash
internal/open/commons/typescript/typescript-react-ui-primitives/scripts/update-primitives.sh
```

Das Script führt `shadcn add --yes --overwrite` über jede Component aus, die `shadcn info --json` meldet, und über das Style-Item `style`; Schritte und Exit-Codes stehen in seinem Header. Ein zweiter Lauf direkt nach dem ersten ändert keine Datei.

Ein neues Primitive fügt dieser Befehl hinzu; er schreibt jede installierte Component mit neu:

```bash
internal/open/commons/typescript/typescript-react-ui-primitives/scripts/update-primitives.sh <name>
```

Eine Dependency, die der Catalog nicht führt, trägt pnpm mit `^`-Range in `pnpm-workspace.yaml` ein. Das Script bricht dann ab und nennt sie; der Catalog führt exakte Versionen. `add --all` bricht ab, weil die Registry das Item `questionnaire` listet und nicht ausliefert.

## Marker

`update-primitives.sh` schreibt vor `oxfmt` den Marker aus ADL 0180 in die ersten Zeilen jeder `.ts`/`.tsx`-Datei unter `src/components/`, `src/hooks/` und `src/lib/`:

```tsx
// GENERATED by shadcn CLI — do not edit by hand.
// Source: https://ui.shadcn.com/r/styles/radix-vega/separator.json
// Run internal/open/commons/typescript/typescript-react-ui-primitives/scripts/update-primitives.sh; a customization belongs in a wrapper under internal/open/commons/typescript/typescript-react-ui/src/components/primitives/<name>/.

"use client";
```

Das Registry-Item der `Source:`-Zeile ist der Dateiname ohne Endung, der Style kommt aus `style` in `components.json`. Die Leerzeile hinter dem Marker hält ihn in Zeile 1: `sortImports` von `oxfmt` verschiebt einen Kommentar, der am ersten Import steht, mit diesem Import. Einen vorhandenen Marker ersetzt das Script. `check_file_edit` in `.claude/hooks/pre-tool-use-guard.sh` lehnt jeden Agent-Edit an einer Datei mit Marker ab.

`test/generated-marker.test.ts` prüft den Marker im Modul-Build `./gradlew :internal:open:commons:typescript:typescript-react-ui-primitives:build` und schlägt mit dem Pfad jeder Datei fehl, deren erste vier Zeilen vom Marker abweichen.

Der Job `⏲ update the shadcn primitives` in `gitlab-ci.d/schedule/run-housekeeping.yml` führt das Script täglich im Schedule `Run Housekeeping` aus. Bei einem Diff pusht er den Branch `robot/shadcn-primitives` und öffnet einen MR ohne Approval; `scripts/describe-update.sh` schreibt dessen Beschreibung.

`components.json` legt den Style `radix-vega` fest. Die CLI lädt `https://ui.shadcn.com/r/styles/radix-vega/<name>.json`. Der Catalog von `pnpm-workspace.yaml` führt die Version der CLI als `shadcn`.

Die CLI schreibt:

| Pfad                        | Inhalt                                                                                           |
| --------------------------- | ------------------------------------------------------------------------------------------------ |
| `src/components/<name>.tsx` | die Component und jede Component, die sie importiert (`command` → `input-group`, `textarea`)     |
| `src/hooks/<name>.ts`       | ein Hook, den eine Component mitliefert (`sidebar` → `use-mobile`)                               |
| `src/lib/<name>.ts`         | eine Hilfsfunktion, die ein Item mitliefert (`style` → `utils`, von keiner Component importiert) |
| `src/shadcn-theme.css`      | CSS des Style-Items `style`: Imports von `tw-animate-css` und `shadcn/tailwind.css`, Base-Layer  |
| `package.json`              | Dependencies der Components                                                                      |

Die Components importieren einander relativ (`./button`, `../hooks/use-mobile`). `aliases.utils` ist das Package `cn`, aus dem die Components `cn` importieren.

`chart` verlangt `recharts@3.8.0`. `catalogMode: strict` in `pnpm-workspace.yaml` lehnt jede Version außerhalb des Catalog mit `ERR_PNPM_CATALOG_VERSION_MISMATCH` ab, und die CLI bricht vor der ersten Datei ab. `update-primitives.sh` startet die CLI deshalb mit `pnpm_config_catalog_mode=prefer`: `pnpm add` trägt die Version in `package.json` ein, das Script setzt sie zurück auf `catalog:`.

`tailwind.css` in `components.json` nennt `src/shadcn-theme.css`. `shadcn add style` schreibt dorthin das CSS des Style-Items `style`: `@import "tw-animate-css"`, `@import "shadcn/tailwind.css"` und einen Base-Layer mit `border-border outline-ring/50` auf jedem Element. `shadcn/tailwind.css` definiert die Custom Variants der Primitives (`data-open`, `data-closed`, `data-checked`, `data-unchecked`, `data-selected`, `data-disabled`, `data-active`, `data-horizontal`, `data-vertical`), die Utilities `no-scrollbar`, `scroll-fade-*` und `shimmer-*` mit ihren `@property`-Registrierungen und Keyframes sowie die Accordion-Keyframes. Die CLI bricht mit `ENOENT` ab, wenn `src/shadcn-theme.css` fehlt.

`src/tailwind-sources.css` importiert `src/shadcn-theme.css`. Jede App erhält das CSS über die Manifest-Kette `typescript-react-ui/tailwind-sources.css` → `typescript-react-ui-primitives/tailwind-sources.css`. `@custom-variant` gilt für das ganze Stylesheet der App: `data-open:` kompiliert zu `[data-state="open"]` oder `[data-open]:not([data-open="false"])`, `data-disabled:` zu `[data-disabled="true"]` oder `[data-disabled]:not([data-disabled="false"])`. `shadcn` und `tw-animate-css` stehen deshalb in `dependencies`: das Stylesheet jeder App löst sie beim Build auf.

Die Theme-Tokens definiert `@neckar-hub/tailwind-config`; `src/shadcn-theme.css` definiert keine Theme-Variable.

Ein Registry-Item kann Dependencies des Style-Items `index` weglassen, die seine Component importiert: `class-variance-authority`, `cn`, `lucide-react`, `radix-ui`. `pnpm --filter @neckar-hub/typescript-react-ui-primitives add <dependency>` trägt sie als `catalog:` ein.

## Lint

`oxlint.config.ts` schaltet pro Datei jede Regel ab, die der CLI-Output verletzt. Ein Override nennt die Datei in `files`.

## Consumer

`@neckar-hub/typescript-react-ui` ist der einzige Consumer. Apps und andere Packages importieren Components aus den Kategorie-Exports `@neckar-hub/typescript-react-ui/<kategorie>`. `verifyPnpmWorkspaceDependencies` meldet jede andere `package.json` eines registrierten pnpm-Moduls, die `@neckar-hub/typescript-react-ui-primitives` deklariert, mit Pfad und Zeile.

## Exports

| Export                                                    | Datei                       |

| `@neckar-hub/typescript-react-ui-primitives/ui/<name>`    | `src/components/<name>.tsx` |

| `@neckar-hub/typescript-react-ui-primitives/lib/<name>`   | `src/lib/<name>.ts`         |
